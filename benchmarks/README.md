# benchmarks/

The evaluation harness and the results it produces. Arguably the most important folder in the project — this is what proves the model is actually good, not just trained.

This folder holds:
- Baseline methods that aren't deep learning at all: Otsu thresholding on VV backscatter, and Otsu combined with HAND/slope masking. These exist so the CNN results can be judged against something simple, not just against each other.
- The metrics code: IoU, F1, precision, recall (per flood event, not just averaged — averages can hide a model that only works on one event), plus calibration error and efficiency numbers (latency, throughput, VRAM).
- `RESULTS.md`, generated by a single command, with the full models-vs-metrics table.

Per the project rule: no result goes in the README without the baseline it beat and the metric used.
